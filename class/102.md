# 2. Python Object Model (Critical)

This is where most engineers stop — but production engineers must know this.

Topics:

* Everything is an object
* Classes are objects
* `type`
* `object`
* Relationship:

```
object -> base class of everything
type -> metaclass of classes
```

Important checks:

```
type(A)
type(a)
A.__class__
a.__class__
```

Concepts:

* class creation
* instance creation

---

# 1. First Principle: Everything Is an Object

In Python:

* integers → objects
* strings → objects
* functions → objects
* classes → objects
* modules → objects

Everything is a **heap allocated object with metadata**.

Example:

```python
x = 10

print(type(x))
print(id(x))
```

Output:

```
<class 'int'>
140245567
```

Meaning:

```
x -> reference
     ↓
   object (value=10, type=int)
```

### Important

Variables **do not store values**.

They store **references to objects**.

```
x = 10
y = x
```

Memory model:

```
x ─┐
   ├──> [10 object]
y ─┘
```

Production implication:

* assignment is **cheap**
* copying objects **may not happen**

---

# 2. Classes Are Also Objects

This shocks most developers.

```python
class A:
    pass
```

Check:

```python
print(type(A))
```

Output:

```
<class 'type'>
```

Meaning:

```
A is an object
created by the type class
```

Memory:

```
A  ----> class object
           |
           | attributes
           | methods
           | metadata
```

You can prove this.

```python
A.x = 10

print(A.x)
```

Works because **A is an object**.

---

# 3. Instances Are Objects Too

```python
class A:
    pass

a = A()
```

Check:

```python
print(type(a))
```

Output:

```
<class '__main__.A'>
```

Meaning:

```
a is instance of class A
```

Memory:

```
a ----> instance object
           |
           | __dict__
```

Example:

```python
a.x = 10

print(a.__dict__)
```

Output

```
{'x': 10}
```

---

# 4. The Core Relationship (Memorize This)

The Python object system is built on **two roots**.

```
object  -> base class of everything
type    -> metaclass of classes
```

### Visual Model

```
        object
           ↑
           |
         class A
           ↑
           |
         instance a
```

But classes themselves are objects:

```
         type
          ↑
          |
        class A
```

So:

```
instance → class → type
```

---

# 5. Verify Everything Yourself

Code:

```python
class A:
    pass

a = A()

print(type(a))
print(type(A))

print(a.__class__)
print(A.__class__)
```

Output:

```
<class '__main__.A'>
<class 'type'>
<class '__main__.A'>
<class 'type'>
```

Meaning:

```
a.__class__ = A
A.__class__ = type
```

---

# 6. The Real Root

Check this.

```python
print(type(object))
print(type(type))
```

Output:

```
<class 'type'>
<class 'type'>
```

Yes.

```
type is instance of itself
```

And also:

```
object is instance of type
```

Final structure:

```
object
  ↑
  | (base class)
  |
user classes

type
  ↑
  |
metaclass of classes
```

Weird but intentional.

# 7. What Actually Happens When You Write a Class

When Python sees:

```python
class A:
    x = 10

    def foo(self):
        pass
```

Python internally does roughly this:

```
1. create namespace dict
2. execute class body inside it
3. call type()
4. produce class object
```

Equivalent code:

```python
A = type(
    "A",
    (),
    {
        "x": 10,
        "foo": lambda self: None
    }
)
```

Yes.

**Classes are created by calling `type`.**

# 8. Instance Creation (Critical for Production)

When you run:

```python
a = A()
```

Python does:

```
1. call A.__new__()
2. create instance
3. call A.__init__()
```

Example:

```python
class A:

    def __new__(cls):
        print("NEW")
        return super().__new__(cls)

    def __init__(self):
        print("INIT")

a = A()
```

Output:

```
NEW
INIT
```

Production implication:

```
__new__ -> object allocation
__init__ -> object initialization
```

---

# 9. Attribute Lookup (Production Critical)

If you do:

```python
a.x
```

Python searches in this order:

```
1 instance dict
2 class dict
3 parent classes (MRO)
```

Example:

```python
class A:
    x = 100

a = A()

print(a.x)
```

Python:

```
a.__dict__ -> not found
A.__dict__ -> found
```

Never forget this chain.

```

   ↓

```

And remember:

```

```
