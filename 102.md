# 2. Python Object Model (Critical)

This is where most engineers stop — but production engineers must know this.

Topics:

* Everything is an object
* Classes are objects
* `type`
* `object`
* Relationship:

```
object -> base class of everything
type -> metaclass of classes
```

Important checks:

```
type(A)
type(a)
A.__class__
a.__class__
```

Concepts:

* class creation
* instance creation
